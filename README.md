# replace_placeholder

`shared/lua/replace_placeholder.lua` — 一个 `lua_filter`，对候选做实时修饰：类型符号、太极过滤、占位符替换

在 schema 的 `engine.filters` 中加入 `lua_filter@*replace_placeholder` 启用。

## 功能概览

| 功能       | 作用                                                          |
| ---------- | ------------------------------------------------------------- |
| 类型符号   | 按配置为候选注释追加类型标记                                  |
| 太极过滤   | 丢弃注释含 ☯ 标记的候选                                       |
| 占位符替换 | 仅对指定类型候选，展开 strftime 令牌、`字%N` 重复与 `%%` 转义 |

## 类型符号

从配置 `super_comment/cand_type` 读取「候选类型 → 符号」映射，为匹配类型的候选注释追加符号；
注释已以该符号结尾时不重复追加。注释为 `~` 时跳过。

```yaml
super_comment:
  cand_type:
    user_table: ""
    abbrev: ""
```

## 太极过滤

注释中含 ☯（`U+262F`）的候选整条丢弃，用作隐藏标记。默认硬编码开启。

## 占位符替换

仅作用于 `abbrev`、`user_table` 类型的候选文本（`TARGET_TYPES`）。

处理顺序（`replace_formats` 流水线）：

1. `%%` 转义保护（先取出字面 `%`）
2. strftime 令牌替换
3. `字%N` 重复展开
4. 还原转义占位符

### 转义

`%%` 输出字面 `%`。例如：

- `%%y` → `%y`
- `100%%` → `100%`

由于 `%%` 优先保护，`%%3` 输出字面 `%3`（不会被当作重复）。

### 重复语法

`<字符>%<数字>` 将前一个 UTF-8 字符重复 N 次（N 为一位数字 1–9）。例如：

- `令%3申%5` → `令令令申申申申申`
- `哈%3` → `哈哈哈`

`%0` 无效，保留原样（`字%0`）。

### strftime 令牌

`%` 开头、后接单个 ASCII 字母的令牌交由 Lua `os.date` 求值，
**支持完整 strftime**（依赖系统 locale）。常用令牌：

| 令牌      | 含义               | 示例输出                   |
| --------- | ------------------ | -------------------------- |
| `%y`      | 年份（2位）        | `26`                       |
| `%Y`      | 年份（4位）        | `2026`                     |
| `%C`      | 世纪               | `20`                       |
| `%m`      | 月份（补零）       | `09`                       |
| `%b`/`%h` | 缩写月份           | `Sep`                      |
| `%B`      | 全称月份           | `September`                |
| `%d`      | 日（补零）         | `08`                       |
| `%e`      | 日（空格补齐）     | ` 8`                       |
| `%j`      | 年内第几天         | `251`                      |
| `%H`      | 时 00–23           | `14`                       |
| `%I`      | 时 01–12           | `02`                       |
| `%M`      | 分（补零）         | `30`                       |
| `%S`      | 秒（补零）         | `05`                       |
| `%p`      | AM/PM              | `PM`                       |
| `%a`      | 缩写星期           | `Tue`                      |
| `%A`      | 全称星期           | `Tuesday`                  |
| `%w`      | 星期（0=周日）     | `2`                        |
| `%u`      | ISO 星期（1=周一） | `2`                        |
| `%U`      | 周数（周日起始）   | `36`                       |
| `%W`      | 周数（周一起始）   | `37`                       |
| `%V`      | ISO 周数           | `37`                       |
| `%g`      | ISO 周两位年份     | `26`                       |
| `%G`      | ISO 周四位年份     | `2026`                     |
| `%c`      | 本地日期时间       | `Tue Sep  8 14:30:05 2026` |
| `%D`      | `%m/%d/%y`         | `09/08/26`                 |
| `%F`      | `%Y-%m-%d`         | `2026-09-08`               |
| `%x`      | 本地日期           | `09/08/26`                 |
| `%X`      | 本地时间           | `15:41:58`                 |
| `%T`      | `%H:%M:%S`         | `14:30:05`                 |
| `%R`      | `%H:%M`            | `14:30`                    |
| `%r`      | 12 小时时间        | `02:30:05 PM`              |
| `%z`      | 时区偏移           | `+0800`                    |
| `%Z`      | 时区名             | `CST`                      |
| `%n`      | 换行               | `\n`                       |
| `%t`      | Tab                | `\t`                       |

#### 中文变体

| 令牌 | 含义             | 示例输出 |
| ---- | ---------------- | -------- |
| `%Q` | 星期全称（中文） | `星期二` |
| `%q` | 星期简称（中文） | `周二`   |
| `%P` | 时段（中文）     | `下午`   |

`%P` 时段按小时划分：<6 凌晨、<12 上午、<14 中午、<18 下午、其余晚上。

Lua `os.date` 不支持的码（如 `%s` 时间戳、`%f`、`%O` 等）经 pcall 防护后**原样保留**，
不会报错。`%E`/`%O` 修饰符前缀（如 `%Ey`）不支持。
