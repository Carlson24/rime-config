# super_filter

`wanxiang*/lua/wanxiang/super_filter.lua` — 一个 `lua_filter`，对候选词做实时修饰：转义序列解析、日期时间令牌替换

## 基础转义

在词典词条文本中使用以下转义序列，输出时自动展开：

| 转义 | 输出     |
| ---- | -------- |
| `\n` | 换行     |
| `\r` | 回车     |
| `\t` | Tab      |
| `\s` | 空格     |
| `\z` | 零宽空格 |

### 重复语法

`<字符>\<数字>` 将前一个 UTF-8 字符重复 N 次（上限 200）。例如：

- `哈\3` → `哈哈哈`
- `─\10` → `──────────`

### 保护块

用 `[[...]]` 包裹的内容不参与任何转义处理，原样保留。
例如 `[[hello\nworld]]` 中的 `\n` 不会被展开。

## 日期时间令牌

候选词文本中以 `%` 开头的令牌会被替换为当前日期时间。
例如 `今天%Y年%m月%d日 %W` → `今天2026年07月31日 星期五`。

| 令牌 | 含义            | 示例输出 |
| ---- | --------------- | -------- |
| `%Y` | 年份（4位）     | `2026`   |
| `%y` | 年份（2位）     | `26`     |
| `%m` | 月份（补零）    | `07`     |
| `%N` | 月份（不补零）  | `7`      |
| `%d` | 日期（补零）    | `31`     |
| `%j` | 日期（不补零）  | `31`     |
| `%W` | 星期（全称）    | `星期五` |
| `%w` | 星期（简称）    | `周五`   |
| `%H` | 时(24h，补零)   | `14`     |
| `%G` | 时(24h，不补零) | `14`     |
| `%I` | 时(12h，补零)   | `02`     |
| `%l` | 时(12h，不补零) | `2`      |
| `%M` | 分（补零）      | `05`     |
| `%S` | 秒（补零）      | `30`     |
| `%p` | am/pm（小写）   | `pm`     |
| `%P` | AM/PM（大写）   | `PM`     |
| `%A` | 时段（中文）    | `下午`   |
| `%O` | 时区偏移        | `+0800`  |
| `%o` | 同上            | `+0800`  |

> 日期时间令牌在进入保护块 `[[...]]` 之前处理，因此 `[[%Y]]` 也会被替换。如有冲突需求建议调整词典避免。
